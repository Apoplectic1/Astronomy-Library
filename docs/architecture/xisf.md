# Astronomy.XISF

*(ARCHITECTURE reference set — split out of the root `ARCHITECTURE.md` 2026-08-11, one file per buildable module; the root file is the index. Charter: subsystem mechanics — how this module is built and works.)*

- **`Astronomy.XISF`** — `net10.0-windows` (`AnyCPU;x64`, like Core — AnyCPU enables the standalone `dotnet build`), `LangVersion latest`, `Nullable enable`, `ImplicitUsings enable`. XISF (PixInsight image format) read library. Tier 1 surface (2026-05-18) is header-only read: `XisfHeader.cs` (typed FITS-keyword accessors carrying value + comment per keyword) and `XisfHeaderReader.cs` (header-only XISF parser, pure managed `XDocument.Parse()`, no native dep). Since 2026-07-29 the reader also harvests the `<Image>` element's **mandatory `geometry` attribute** (not just `<FITSKeyword>` entries — geometry was present on all 18,650 measured frames while the pixel-dimension keyword duplicates were absent on 63, and the two never disagreed), and `XisfHeader` derives the angular field from those pixel dimensions + `FOCALLEN` + `XPIXSZ`. **No binning multiplier anywhere in that derivation** — `XPIXSZ` is already binning-adjusted, so multiplying would double the field for the 15.8% of the library shot at bin 2. Ported from `XisfFileManager/Files/XisfXmlReader.cs` + a subset of `XisfFileManager/Keyword/KeywordList.cs`. Designed for sharing across XFM, TP, IS, and the user's other apps without dragging NINA's heavyweight `NINA.Image.FileFormat.XISF` (which is coupled to `NINA.Profile` / WPF / image-data factories and forces pixel decode on every read). **Tier 3 (block codecs + verified image read) shipped 2026-08-06/07** — the module is no longer header-only: `Compression/` (`XisfBlockCompression`: symmetric zlib/lz4/lz4hc/zstd ± byte-shuffle, five spec checksum algorithms + legacy-alias canonicalization at `BlockCompressionInfo.Parse`, optional zstd level), `XisfImageReader.ReadImageAsync`, `XisfChecksumVerifier.VerifyAsync`, and `XisfBlockRewriter.RewriteAsync` (byte-preserving surgical block re-store). **Normative specs: `openspec/specs/xisf-block-compression/` + `xisf-image-read/`**; shipped record `CHANGELOG.md` §§ 2026-08-06/07; adopters `CONSUMERS.md` (XFM since v2.4.0). Tiers 2 & 4 (metadata write-back, image write) are scoped in `ROADMAP.md` § *Open: Astronomy.XISF Tiers 2 & 4*. Tier-3 mechanics below.

## Tier-3 mechanics (2026-08-06/07)

**Module shape.** A symmetric encode/decode block-codec layer plus three consumers of it: a shared `XisfXmlLoader` signature/XML front end serves both the header and pixel paths (the header path stays pixel-free and byte-identical); `XisfImageReader.ReadImageAsync` is locate → file-bounds check → verify declared checksum → decompress → declared-length check → verified pixel buffer (`XisfImageData`); `XisfChecksumVerifier.VerifyAsync` is the cheap detect-only integrity check, returning a three-way `Verified`/`NoChecksum`/`Mismatch` verdict rather than throwing on a digest mismatch (all three arms are consumer surface); `XisfBlockRewriter.RewriteAsync` re-stores the primary image block under a new codec (or `None`) via temp file + atomic replace, verifying the declared checksum before re-encoding.

**Block-codec producer interop** — pinned to real producer behavior (decisions: `openspec/changes/archive/2026-08-06-xisf-codecs-and-image-read/design.md` §§ D1-4, D7):
- **LZ4 is the raw block format** (not LZ4 frame), so decode requires the declared uncompressed size and a size disagreement is a hard error.
- **Checksums cover the stored (post-compression) bytes**, matching NINA/PixInsight.
- The `+sh` byte-shuffle variant applies automatically iff itemSize > 1; compression levels mirror NINA's (zlib SmallestSize / LZ4 fast / LZ4HC HC / zstd 1).
- SHA3 tokens depend on OS support and are deliberately unguarded fail-fast; sub-block `compression` attribute forms are rejected outright.
- Both codec deps (`K4os.Compression.LZ4`, `ZstdSharp.Port`) are pure-managed, preserving the module's no-native / standalone-`dotnet build` property.
- **A legacy non-hyphenated checksum token (`sha1`/`sha256`/`sha512`) is valid input, not a contract violation**: canonicalized to spec form at the single `BlockCompressionInfo.Parse` site (never aliased inside `ComputeChecksumHex`), so `ChecksumName` is always spec-form, a re-save rewrites the attribute to the spec token for free, and fail-fast-on-unknown-algorithm stays intact for genuinely unrecognized tokens.

**Write-side asymmetry — deliberate.** The read side honors all five spec checksum algorithms plus the legacy aliases; every block the library **writes** is stamped `sha-1` (hard-coded in `XisfBlockCompression.Compress`, inherited unchanged by `XisfBlockRewriter`) — so a re-store silently downgrades a sha-256/sha-512 file's *declared algorithm*. And `Compress` never falls back to storing uncompressed when a codec fails to shrink a block: a stored-uncompressed block reads back as uncompressed and would be re-attempted on every future save.

**Zstd level is encode-side only.** Any zstd decoder reads any level — no read path, attribute, or checksum semantics change with it — and non-zstd families throw rather than silently ignoring a level. The reason is measured: shuffled 16-bit frames come out ~11% smaller at zstd-19 than zlib-SmallestSize, a win appearing only past the level-15+ strategy switch — so a level pays on archival re-stores, while interop writes keep the level-1 default matching NINA's bytes (`CHANGELOG.md` § 2026-08-07 zstd-level).

**Rewriter textual-edit contract.** Byte-for-byte header preservation is achieved by **literal text substitution, never re-serialization**: each edited attribute must appear verbatim as `name="value"` exactly once — entity-encoded, reformatted, or duplicated attribute text makes the rewrite throw rather than guess. Because a changed `location` digit width changes the XML length and therefore every attachment offset, layout is re-converged iteratively (from the original text each pass, capped at 10 iterations) while honoring a declared `XISF:BlockAlignmentSize`. On any failure the temp file is deleted and the target is never touched.
